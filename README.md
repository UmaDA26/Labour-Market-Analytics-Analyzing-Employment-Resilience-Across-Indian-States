# Labour-Market-Analytics-Analyzing-Employment-Resilience-Across-Indian-States

# 📌 Project Overview

-This project focuses on analyzing India's labour market using data from the Periodic Labour Force Survey (PLFS). The analysis combines multiple labour-market indicators to create a single, clean, analysis-ready dataset.

-The project is initially developed using Python and Pandas, with the objective of understanding labour-force participation, employment, unemployment, and sector-wise employment trends across different states, years, and quarters.

-The project will later be extended to Power BI for interactive visualization and dashboard development.

# 🎯 Objectives

The main objectives of this project are:
* To collect and combine multiple PLFS datasets related to:
  
-Labour Force Participation Rate (LFPR)

-Worker Population Ratio (WPR)

-Unemployment Rate (UR)

-Sector-wise employment distribution

* To merge the datasets using appropriate common keys such as State, Year, and Quarter.

* To clean and preprocess the merged dataset by handling:

Missing values

Inconsistent formats

Duplicate records

* Structural mismatches resulting from data merging

*To create a single, clean and analysis-ready dataset.

*To prepare the data for further labour-market trend analysis and visualization.

# 📊 Dataset

The project uses data from the Periodic Labour Force Survey (PLFS).

The datasets contain labour-market information across different:

States

Years

Quarters

Labour-market indicators

Employment sectors
